# Product

**FlotaAuto** — Sistema de gestión de flotas vehiculares.

## Descripción

Plataforma web para administrar flotas de vehículos de organismos o empresas.
Permite registrar y hacer seguimiento de vehículos, reparaciones, VTV, documentación,
conductores, novedades e incidentes.

## Audiencia

- Administradores de flota
- Encargados de mantenimiento
- Gestores de organismos con vehículos propios

## Tono

- Profesional
- Claro y directo
- Confiable
- Moderno sin ser frívolo

## Funcionalidades principales

- Gestión de vehículos (alta, baja, modificación)
- Registro de reparaciones con estado (En Reparacion / Reparado)
- Control de VTV y seguro con alertas de vencimiento
- Gestión de conductores asignados
- Documentación por vehículo
- Dashboard con resumen de flota
- Estadísticas de costos y actividad

## Evitar

- Lenguaje excesivamente técnico
- Interfaces sobrecargadas de información
- Flujos de navegación complejos
